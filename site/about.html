METHODOLOGY

Why greatness is the only ranking that isn't noise.

The contract's math

The original Loot contract generates each item with a single hash per slot. It picks a base item with rand % length and greatness with rand % 21. Every item list and every modifier list is drawn the same way — uniformly. There are no rare weapons, no rare suffixes, no rare anything. Observed frequency differences over 8,000 bags are sampling noise, not design.

Greatness is different: it has 21 levels, it unlocks the visible decorations ("of Skill", "Grim Shout", +1), and it stacks across all eight slots. It is the only per-item value whose sum creates a real distribution. So the index ranks bags by the sum of the eight greatness rolls.

Ranking rules

Score tuple, in order:

  1. Greatness sum (0–160 possible, 22–140 observed)
  2. Number of +1 items (greatness 20)
  3. Number of named items (greatness ≥ 19)
  4. Best single item
  5. Lower bag ID (deterministic display order only)

Bags with the same score tuple share the same rank and percentile. top_pct counts strictly better tuples only, so a true tie never pushes another bag down.

What we don't rank

Item rarity. Under uniform generation it is noise. Any site claiming a rare Ghost Wand is measuring its own sample, not the contract.

Visible names. Hidden modifiers are known for all 8,000 bags, so a bag's rank is final even before its greatness is revealed. This is why the numbers here can differ from tools that only read visible names.

Data and verification

The dataset is generated from the canonical stark-loot verbose fixture — all 8,000 bags, every hidden modifier — and numeric IDs, tiers, slots, and combat types are parsed directly from the Cairo source.

Every bag page can verify itself against the deployed stateless stark_loot contract: one get_packed_bag(bag_id) call returns a single felt, which the page decodes with the documented 29-bit wire layout and compares field by field. 40 fields, no trust required.

Roadmap

  • Dungeon power score — once the Loot Dungeon's bag mechanic is public, a second score using real game stats and modifier effects.
  • Item boards — best individual items per slot.
  • Collections — rank a wallet holding several bags.
  • Open data — the full dataset is a plain JSON build anyone can reuse.
